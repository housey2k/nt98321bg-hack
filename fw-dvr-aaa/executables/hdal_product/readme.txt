DVR_4CH (98321 system board):
   Display Video/YUV420 1920x1080 + GUI/ARGB1555 1920x1080 (HDMI, VGA output)
   Display Video/YUV422 720x576 + GUI/ARGB1555 720x576 (CVBS output)
   Encode main 4CH 1080p(15fps) + sub 4CH 960h(15fps)
   Decode 4CH 1080p(15fps) 

DVR_8CH (98323 system board):
   Display Video/YUV420 1920x1080 + GUI/ARGB1555 1920x1080 (HDMI, VGA output)
   Display Video/YUV422 720x576 + GUI/ARGB1555 720x576 (CVBS output)
   Encode main 8CH 1080p(15fps) + sub 8CH 960h(15fps)
   Decode 8CH 1080p(15fps)

NVR_4CH (98321 system board):
   Display Video/YUV420 1920x1080 + GUI/ARGB1555 1920x1080 (HDMI, VGA output)
   Display Video/YUV422 720x576 + GUI/ARGB1555 720x576 (CVBS output)
   Decode 4CH 1080p(30fps)

NVR_8CH (98323 system board):
   Display Video/YUV420 3840x2160 + GUI/ARGB1555 1920x1080 (HDMI, VGA output)
   Display Video/YUV422 720x576 + GUI/ARGB1555 720x576 (CVBS output)
   Decode 8CH 1080p(22fps)

DVR_4CH_mini (98321 system board):
   Display Video/YUV420 1280x1024 + GUI/ARGB1555 1280x1024 (HDMI, VGA output)
   Encode main 4CH 720p(30fps) + sub 4CH CIF(30fps)
   Decode 1CH 720p(30fps)

DVR_8CH_max (98323 system board):
   Same as DVR_8CH, plus addition 4K support for testing.
